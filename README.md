🗂️ A simulation application management system that allows users to browse, install, and uninstall apps, while tracking usage statistics by category.
The project provides a user-friendly catalog interface, supports category sorting, and maintains accurate statistics for installed applications. Registration is required to access the system.

🏠 Overview

This application lets users explore a catalog of apps, sorted by categories such as Entertainment, Social, Productivity, and more. Users can install or uninstall applications and see statistics for installed apps per category. A registration system ensures secure access and personalized usage tracking.

💻 Tech Stack

C

Local storage for app and user data

Git/GitHub for version control

🚀 Features

- User registration and login system

- Browse the catalog of applications

- Filter and sort apps by categories (Entertainment, Social, etc.)

- Install and uninstall applications

- View real-time statistics on installed apps per category

- Secure access and user management

🛠️ How to Run the Project

Clone the repository:

git clone https://github.com/Iasminaaaaa/Application-Management-System.git

Open the solution in Visual Studio / CodeBlocks

Build and run the project

Use the registration form to create an account and start managing applications
